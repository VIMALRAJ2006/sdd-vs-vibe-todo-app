# Spec Driven Development (SDD) Todo App

This project demonstrates **Spec Driven Development (SDD)** using **OpenSpec** and **Cursor AI**.

The application was developed using a specification-first workflow where requirements, proposals, and tasks were defined before implementation.

---

# SDD Workflow

The project follows the OpenSpec lifecycle:

1. Propose
2. Apply
3. Archive

Workflow used:

Specification → Proposal → Tasks → AI Implementation → Archive

---

# Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Dark/Light mode
- Task categories
- Due dates
- Task filters
- Responsive UI
- Accessibility support
- localStorage persistence

# Difference Between Vibe Coding and SDD

| Vibe Coding | Spec Driven Development |
|---|---|
| Prompt-based generation | Specification-first workflow |
| Fast prototyping | Structured engineering |
| No source of truth | Spec is source of truth |
| Harder to maintain | Easier maintenance |
| Informal workflow | Proposal and task workflow |
